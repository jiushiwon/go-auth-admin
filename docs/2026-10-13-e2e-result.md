## 发现的真实问题（不属于"前端也要搞"范围，但 e2e 跑出来的）

### P0-1 后端：UserListVO 的 roles/posts 永远为 null
- 位置：`backend/service.go:582`
- 现象：`userToVO(&u, orgName, nil, nil)` 传 nil
- 影响：前端 `users` 列表页每一行看不到用户的角色和岗位
- Java 行为：UserPageResp 的 list 元素含 `roles: List<RoleResp>` `posts: List<PostResp>`
- 修复方向：list 时 N+1 或 join 查 user_role + user_post，再填 SimpleRefVO

### P1-1 seed：没建 demo app
- 位置：`backend/seed.go` 末尾
- 现象：`/api/apps` 返回空（0 个 app）
- 影响：开放接口的 e2e 自动化要 admin 先 POST /api/apps 才能拿 apiKey/apiSecret
- Java 行为：RuoYi-Vue-Plus seed 阶段会建 1 个 `ruoyi-vue` demo app
- 修复方向：seed 末尾 `app := saveApp("demo-app", "演示应用", 1)`，并 seed 一对 apiKey/apiSecret
